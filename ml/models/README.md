# Modeller

Denne mappen er for lagrede modeller fra trening (f.eks. `.joblib`, `.pkl`, `.pt`).

Viktig:
- Store modellfiler skal normalt **ikke** versjoneres i git.
- Bruk gjerne versjonering via filnavn/metadata, eller lag en egen “release”-plassering senere (f.eks. GitHub Releases eller artefaktlagring).
